🎲 Dice Roller – Python Tkinter
📌 Beschreibung

Dieses Projekt ist eine einfache Dice-Roller-Anwendung, die mit Python und Tkinter entwickelt wurde.
Mit einem Klick auf den Button wird ein zufälliger Würfelwert von 1 bis 6 generiert und sowohl als Zahl als auch als Würfelsymbol angezeigt.

⚙️ Funktionen

• Zufälliges Würfeln (1–6)

• Anzeige des Ergebnisses als Zahl

• Anzeige passender Würfelsymbole (⚀–⚅)

• Einfache grafische Benutzeroberfläche (GUI)

🛠️ Verwendete Technologien

• Python

• Tkinter (GUI)

• random (Zufallszahlengenerierung)
